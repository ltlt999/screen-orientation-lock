# 真机自测清单

> 开发机上没有连接的安卓设备，以下条目需在手机上逐条验证。按顺序做，每条做完打勾。
> 编译、单元测试、lint 均已在开发机上通过（75 个单元测试、lint 0 error），
> 真机要验的是那些只能靠真机确认的行为。

## 准备

- [ ] 安装 `app-debug.apk`，应用名显示为「屏幕方向锁」
- [ ] 首次打开，界面是深色的，不是黑屏；标题「屏幕方向锁」清晰可见
- [ ] 中央手机示意图为暗色描边、缓慢呼吸，中间一个字
- [ ] 顶部出现琥珀色权限引导卡「需要一项权限」
- [ ] 界面所有文字为中文，无英文残留

## 权限

- [ ] 点「去开启」，跳到系统的「修改系统设置」页
- [ ] 打开开关，返回应用，权限卡消失，界面立即可用
- [ ] （Android 13+）首次打开时弹出通知权限请求；允许后下拉通知栏能看到常驻通知

## 锁定功能

- [ ] 点「竖屏」：通知栏出现「竖屏锁定中」；转动手机屏幕不横过来
- [ ] 中央手机示意图旋转到竖立后停住，描边变紫粉渐变
- [ ] 点「反向竖屏」：示意图转 180°，卡片与示意图描边变**橙红**
- [ ] 点「横屏」：屏幕横过来；示意图横躺，描边变青蓝
- [ ] 点「反向横屏」：朝另一侧横躺，橙红描边
- [ ] 点「当前方向」：保持手机不动得到当前方向；再把手机横过来点一次，锁的是横屏，且**示意图也跟着横过来**（这一条验证 pinnedRotation 接线）
- [ ] 点「自动」：恢复跟随传感器；示意图描边变暗并缓慢呼吸；通知变「未锁定 · 跟随传感器」
- [ ] 切到浏览器、设置等其他应用，方向保持锁定
- [ ] 打开微信 / 支付宝（自身写死竖屏的应用），它仍按自己的方向走 —— **预期行为，不是 bug**

## 旋转动画手感

- [ ] 从「反向横屏」（270°）直接点「竖屏」（0°）：示意图只转四分之一圈，不是转一大圈退回
- [ ] 连续快速切换多个方向，动画不卡、不停在中途

## 通知栏

- [ ] 常驻通知不能左滑划掉
- [ ] 折叠态能看到 3 个按钮：竖屏、横屏、解除；展开后多一个「反向」
- [ ] 点「横屏」：屏幕立即横过来，不用打开应用，通知标题同步变成「横屏锁定中」
- [ ] 竖屏锁定时点「反向」：切到反向竖屏
- [ ] 横屏锁定时点「反向」：切到反向横屏
- [ ] 未锁定时点「反向」：切到反向竖屏（文档定义的回落）
- [ ] 点「解除」：恢复自动旋转
- [ ] 反复点通知按钮，通知标题不会先闪一下「未锁定」再变正确的（这一条验证 lastKnownMode 缓存）

## 守护

- [ ] 锁定竖屏，下拉系统状态栏打开「自动旋转」快捷开关
- [ ] 1 秒内应被自动关掉（ContentObserver 路径），最慢不超过 10 秒（心跳路径）
- [ ] 到设置里关掉「守护模式」，再打开系统「自动旋转」，这次能成功打开、方向不再被强制

## 开机自启

- [ ] 锁定竖屏，重启手机
- [ ] 开机进桌面后方向仍为竖屏，转动手机不横过来
- [ ] 通知栏已有常驻通知，内容与锁定方向一致
- [ ] 全程没有弹出任何界面
- [ ] 若未自动恢复，按应用内「系统适配」卡的说明开启自启动白名单，再重启验证

## 设置开关

- [ ] 关掉「常驻通知」：通知消失，锁定功能仍生效（转动手机仍不横过来）
- [ ] 重新打开「常驻通知」：通知恢复
- [ ] 关掉「开机自启」再重启：开机后方向不自动恢复
- [ ] 重新打开「开机自启」再重启：恢复正常

## 权限被收回（容错）

- [ ] 锁定竖屏后，到系统设置里关掉本应用的「修改系统设置」权限
- [ ] 通知应变为「无法锁定 · 权限已失效」，正文提示去重新开启 —— 不再显示一个假的「竖屏锁定中」
- [ ] 应用不崩溃，守护心跳不导致反复重启（等 1 分钟确认）

## 平板 / 折叠屏（如有）

- [ ] 平板（天然横屏）上点「横屏」：确实横屏，不是反向
- [ ] 平板上点「竖屏」：确实竖屏
- [ ] 折叠屏展开与合上后方向仍正确

## 稳定性与耗电

- [ ] 连续锁定 / 解除 20 次，无卡顿、无闪退
- [ ] 后台放置 1 小时，方向仍保持，通知仍在
- [ ] 系统「电池」里查看本应用耗电，应在低水平（守护是 ContentObserver + 10 秒心跳，不是空转）
